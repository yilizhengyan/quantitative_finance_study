# quant_research

记录量化学习的过程，写几篇笔记与心得；尝试复现简单的策略，不定时更新。

## 目前已有

- `模块碎碎念/` —— 学习笔记
  - `module1_note.ipynb`：量化分析入门。从随机游走、布朗运动讲到伊藤引理与 Black-Scholes，中间用二叉树模型引出对冲与无套利。
  - `module2_note.ipynb`：量化风险与回报。以均值-方差框架为主线，讲两资产与 N 资产的分散化、有效前沿与切点组合，最后转到 Black-Litterman。
- `dmac.py` —— 5/10 日双均线策略回测。tushare 取日线，用 `pre_close` 反推复权因子，信号次日开盘成交，算上佣金、印花税和滑点。
